# Storage Terminal

A client-side Fabric mod for Minecraft 26.3. Stand among your chests, press a key, and see everything stored around you on one screen, then take and deposit items from there. It works on unmodified vanilla servers: the mod only does what a player could do by opening the containers by hand.

**Status:** early development (milestone M0, project skeleton). Nothing playable yet.

## Requirements

- Minecraft 26.3
- Fabric Loader 0.20.1 or newer
- Fabric API

## Commands

- `/storageterminal version`: shows the installed version.

## Building

```bash
./gradlew build
```

The jar ends up in `build/libs/`.
